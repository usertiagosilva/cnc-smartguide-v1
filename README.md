# CNC SmartGuide

Sistema de suporte operacional para máquinas CNC.

## Objetivo
Auxiliar operadores na identificação rápida de falhas e soluções operacionais.

## Tecnologias
- HTML
- CSS
- JavaScript

## Funcionalidades
- Busca de alarmes e problemas
- Checklist operacional
- Diagnóstico rápido
- Interface responsiva
